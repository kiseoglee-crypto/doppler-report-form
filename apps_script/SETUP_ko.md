# "Save to Drive" 설정 방법 (처음 한 번만, 약 5분)

웹페이지에서 **Save to Drive**를 누르면 검사 1건이 자기 구글 시트 **Doppler Report Data**에 한 줄씩 저장돼요.
시트에는 검사 종류별로 탭이 3개 있어요(Arterial / Venous / DVT).

- 저장하는 것: 등록번호, 정확한 검사일, 나이, 성별, 검사 쪽, indication, 혈관별 입력값 전부(Rt/Lt), 자동 판정, CEAP(basic·advanced), 영문 리포트, 나중에 다시 불러올 수 있는 전체 입력값(JSON)
- 저장하지 않는 것: 이름, 생년월일(입력칸 자체가 없음), 검사자·판독의 이름

## 1. 시트 열기
구글 드라이브에서 **Doppler Report Data** 시트를 열어요. 탭 3개(Arterial, Venous, DVT)에 머리글 줄이 이미 들어 있어요.
(시트가 없으면 빈 구글 시트를 새로 만들고 이름을 `Doppler Report Data`로 바꾸면 돼요. 탭과 머리글은 2단계의 setup이 만들고, 머리글은 첫 저장 때 자동으로 채워져요.)

## 2. Apps Script 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
2. 열린 편집기에서 `Code.gs`의 기존 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣어요.
3. 💾 저장 버튼을 눌러요. 프로젝트 이름은 아무거나 괜찮아요(예: `Doppler receiver`).

## 3. 비밀키 만들기 (setup 실행)
1. 편집기 위쪽 함수 선택 칸에서 **setup**을 고르고 **▶ 실행**을 눌러요.
2. 처음 실행하면 권한 요청이 떠요. **권한 검토 → 본인 계정 선택**을 누르고, "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 눌러요. 직접 만든 스크립트가 자기 시트에만 접근하는 거라 괜찮아요.
3. 아래 **실행 로그**에 `SECRET (...): 64자리 문자열`이 나와요. 이 문자열을 복사해 두세요. 이게 비밀키예요.
   - 나중에 다시 보고 싶으면 setup을 한 번 더 실행하면 같은 값이 다시 나와요.
   - 비밀키가 새어 나간 것 같으면 **rotateSecret**을 실행하세요. 새 키가 만들어지고 이전 키는 바로 무효가 돼요.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
3. 설정:
   - 설명: 아무거나 (예: v1)
   - **다음 사용자 인증 정보로 실행: 나(본인 이메일)**
   - **액세스 권한이 있는 사용자: 모든 사용자(Anyone)** ← "Google 계정이 있는 모든 사용자"가 아니라 **모든 사용자**
4. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

## 5. 웹페이지에 연결 (컴퓨터마다 한 번)
1. 리포트 웹페이지를 열고, 오른쪽 **Google Drive settings**를 펼쳐요.
2. **Apps Script web app URL**에 4단계 URL을, **Shared secret**에 3단계 비밀키를 붙여넣어요.
3. **Save settings → Test connection**을 눌러 `Connected: "Doppler Report Data"`가 뜨면 끝이에요.
   - URL과 비밀키만 그 컴퓨터 브라우저에 저장돼요. 환자 정보는 브라우저에 저장되지 않아요.
   - 공용 PC에서 쓴 뒤에는 **Forget**을 눌러 지워 주세요.

## 사용
- **Registration No.**와 **Exam date**를 넣어야 저장돼요.
- 같은 등록번호 + 같은 검사일 + 같은 검사 종류가 이미 있으면 물어봐요: **확인** = 가장 최근 줄 덮어쓰기, **취소** → 다음 창에서 **확인** = 새 줄로 추가, **취소** = 저장 안 함.
- 성공하면 리포트 아래에 초록색으로 `Saved to sheet ... row N`, 실패하면 빨간색으로 이유가 떠요.

## Code.gs를 고친 뒤에는
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 이렇게 하면 URL은 그대로예요.
("새 배포"로 만들면 URL이 바뀌니 웹페이지 설정도 바꿔야 해요.)

## 문제 해결
| 메시지 | 원인 / 해결 |
|---|---|
| Invalid secret | 페이지에 넣은 비밀키가 다름 → setup을 다시 실행해 로그의 값을 붙여넣기 |
| Server not set up | setup을 아직 실행하지 않음 |
| Unexpected response | 액세스가 "모든 사용자"가 아니거나, URL이 `/exec`로 끝나지 않음(`/dev`는 안 됨) |
| Network/CORS error | URL 오타, 인터넷 연결, 배포 삭제됨 |
| Timeout | 구글 쪽 응답 지연 → 잠시 후 다시 저장 (중복 확인 창이 뜨면 이미 저장된 것) |

## 보안 메모
- 웹 앱 URL은 공개 주소지만, 비밀키 없이는 아무것도 못 해요. 또 이 스크립트는 "있는지 확인"과 "줄 저장"만 할 수 있고, **저장된 데이터를 돌려주는 기능이 없어요.** URL과 키가 동시에 새어도 시트 내용을 읽을 수는 없고, 가짜 줄을 넣는 것만 가능해요.
- 시트는 공유하지 말고, 구글 계정에 2단계 인증을 켜 두세요.
- 등록번호가 들어 있어서 개인정보(가명정보)예요. 논문용으로 쓸 때는 IRB에 보관 방법(본인 구글 계정, 비공유)을 적어 두세요.
